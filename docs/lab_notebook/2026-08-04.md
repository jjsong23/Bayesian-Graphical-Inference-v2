## Scaffold-closure correction and simplification

The initially implemented scaffold-closure score was reviewed critically. Its
inverse-log scaffold-degree penalty resembled an Adamic–Adar network heuristic,
but the exact degree normalization, anchor-excess multiplication, noisy-OR
aggregation, and empirical q75 conversion were not established biological
methods for scaffold-mediated protein proximity. That implementation was
therefore rejected and removed from the active workflow.

The revised optional stream uses one transparent binary rule. For proteins
(i) and (j) and any node annotated with the exact `adaptor_scaffold` class (s),
the pair qualifies when both pre-closure edges are strictly above the selected
anchor cutoff:

$$
\exists s:\quad P_{is}>c\ \land\ P_{js}>c.
$$

The default is (c=0.90). Every qualifying pair receives the same support
likelihood (L=0.90). Relative to the workflow's neutral likelihood 0.50, this is
stored as (BF=0.90/0.50=1.8). Nonqualifying pairs remain neutral at BF 1.
Scaffold degree, the number of shared scaffolds, and anchor strength above the
cutoff do not alter the factor. The operation is performed once and closure-
derived edges never become new scaffold anchors.

The stream remains disabled by default because it is derived from the already
integrated edge graph and is not independent experimental evidence. It must be
described as a hypothesis-generating proximity or co-complex signal, not proof
of a direct physical interaction.

### Fixed validation run

The revised rule was evaluated on the default 891-node graph with anchor cutoff
0.90, support likelihood 0.90, and stream weight 1.0:

- annotated scaffold proteins: 195;
- scaffolds with at least two qualifying anchors: 193;
- qualifying protein–scaffold anchors: 14,308;
- qualifying protein pairs: 205,920;
- factor assigned to every qualifying pair: 1.8;
- pairs newly raised above edge probability 0.5: 81,323;
- supported edges before closure: 169,414; and
- supported edges after closure: 250,737.

The immutable validation output is stored in
`results/gui_runs/scaffold_binary_closure_validation_20260804_v2/`. Its compressed
audit table records every qualifying pair, all shared scaffolds, shared-scaffold
count, fixed support likelihood, fixed Bayes factor, and pre/post probability.
