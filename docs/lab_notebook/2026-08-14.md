## Integration decision

Temporal evidence was implemented as an optional fourth-stage path-validation
layer. It is neither a node/edge Bayes factor nor a replacement path score.
The canonical Bayesian `rank` and `path_probability_product` remain unchanged.
Temporal coverage, soft precedence, Kendall uncertainty, and a separate
`temporal_evidence_rank` are appended in a second table.

The feature is disabled by default. The GUI exposes prior degrees of freedom,
alpha, Monte-Carlo draw count, random seed, peak-p correction, and minimum
scored-node coverage.

## Method

Positive replicate reporter pairs were transformed to `log2(dDAVP/vehicle)` at
1, 2, 5, and 15 minutes. Missing/nonpositive pairs remained missing. Replicate
variance was shrunk toward an empirical log-intensity-dependent variance trend:

```text
s_moderated² = (d0 × s0²(I) + d × s_raw²) / (d0 + d)
```

Each gene was represented by the site with the largest peak moderated absolute
t statistic. The corrected peak p was gated at alpha 0.05 by default. For each
retained site, 2,000 normal draws were made from each timepoint mean and
moderated standard error. The absolute-LFC center-of-mass time was calculated
per draw. Paths were annotated with pairwise soft precedence and draw-wise
Kendall tau-a.

## Optional negative node evidence

Added a simple, scope-aware option allowing nondetection to counter the node-
presence hypothesis. When enabled, each eligible but unobserved candidate gets
one configurable Bayes factor below 1 in every active node stream. The default
penalty is BF 0.5, so repeated nondetections multiply the odds toward zero. The
factor is required to remain strictly positive to avoid an irreversible exact-
zero posterior.

The policy is disabled by default to preserve the validated 891-node run.
Protein, RNA, phosphoprotein-response, and collecting-duct abundance streams can
assess all protein candidates. Kinase-activity absence applies only to
ontology-annotated kinases; non-kinases remain neutral. Curated second messengers
are inserted after protein scoring and are not penalized.

The GUI now contains a `Treat eligible nondetections as evidence against a
node` switch and a `Nondetection BF` field. Node posterior plots report how many
candidates fall below the prior. The node audit records source and effective
Bayes factors, eligibility, observation status, penalty application, and
weighted log Bayes factor for each active stream. Initial real-data validation
with the four default node streams and BF 0.5 reduced the selected protein count
from 871 to 282, with 8,625 of 9,170 candidate proteins below the 0.5 prior.
This is a sensitivity-analysis result, not a recommended biological cutoff.
After this addition, all 58 automated tests passed (13 Bayes-factor, 15 path/
target/temporal, and 30 GUI/server/workflow tests), JavaScript syntax validation
passed, and `git diff --check` reported no whitespace errors.
