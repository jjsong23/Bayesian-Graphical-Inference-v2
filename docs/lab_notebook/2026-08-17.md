## Regularized positive-control parameter calibration

Implemented the proposed optional calibration layer in the local workbench. The
scientific interpretation was kept deliberately narrow: supplied nodes and
unordered edges are known-present positive controls, while every unsupplied
hypothesis remains unlabeled. No negative class was inferred from omission.

Node and edge settings are fitted separately. Node calibration precedes node
selection; its fitted weights and Tq multipliers are applied to the complete
candidate catalog. Edge calibration follows selection and endpoint extension,
then its fitted settings are applied to the ordinary full adjacency calculation.
Known edge endpoints can be selected nodes, unselected seed nodes, or external
mouse proteins resolved by the existing UniProt procedure. Raw evidence for new
pairs is generated once and persisted in the incremental SQLite cache.

Each fit minimizes mean negative log posterior probability of the positive
controls plus one quadratic regularizer. Weight changes are standardized by
0.5; multiplicative Tq changes are optimized/log-regularized with scale log(2).
Default lambda is 0.1. Preferred weights are 1. Preferred multipliers are 1,
except PKA-KO kinase activity, PKA-KO phosphoprotein response, and
KinasePredictor, whose default preferred multiplier is 0.1. Bounds are weights
0–3, ordinary multipliers 0.25–4, and phosphoproteomic multipliers 0.05–1.
Zero Tq is invalid and remains prohibited.

The engine is deterministic bounded multi-start
`scipy.optimize.minimize(method="Powell")`. The GUI requests the submitted and
preferred profiles as two starts, collapses them if identical, and keeps the
smallest complete regularized objective. Scaffold-mediated closure is derived
evidence and is never optimized. Cooperative cancellation is checked during
objective evaluations.

Added GUI controls for known-node symbols, known unordered pairs, lambda, and
the phosphoproteomic preferred Tq multiplier. Each calibrated run now preserves
the submitted and effective configurations, parameter tables, target
probabilities before/after fitting, optimizer traces, endpoint-resolution audit,
and a JSON calibration summary.

An external Aqp2 edge smoke test completed on the 892-node graph. For the test
pair Prkaca–Aqp2, the fitted probability moved from approximately 0.99799 to
0.99895 under a single-start test profile. This verifies execution and file
plumbing only; the value is not a performance claim. The permanent methods and
limitations are in `docs/positive_control_parameter_calibration.md`.
