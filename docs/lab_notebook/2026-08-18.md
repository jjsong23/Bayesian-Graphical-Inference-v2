## Calibration implementation handoff and commit notes

Finalized and prepared the regularized positive-control calibration feature for
version control. The implementation adds an optional stage 00 to the local
workbench. Calibration is off by default, so the manually configured workflow
and validated 891-node default remain unchanged unless the user explicitly
enables it.

The feature accepts known-present node symbols and known-present unordered edge
pairs. Unknown hypotheses are not treated as negatives. Node and edge parameters
are optimized independently: node weights and Tq multipliers are fitted before
node selection, while edge weights and Tq/reference multipliers are fitted after
the selected graph has been assembled and any required edge endpoints have been
resolved. Unselected or external known-edge endpoints are explicitly added to
the graph and recorded in the audit rather than silently discarded.

The objective is the mean negative log posterior probability of the supplied
positive controls plus one standardized quadratic regularizer. The GUI default
is lambda = 0.1. Evidence weights are bounded from 0 to 3. Ordinary
Tq/reference multipliers are bounded from 0.25 to 4, and phosphoproteomic
multipliers are bounded from 0.05 to 1. Preferred weights are 1. Preferred
multipliers are 1 except for PKA-KO kinase activity, PKA-KO phosphoprotein
response, and KinasePredictor, whose default preferred multiplier is 0.1.

Optimization uses deterministic bounded SciPy Powell with up to two distinct
starts: the submitted configuration and the preferred anchor profile. Tq values
are optimized on the log scale. Derived scaffold closure is held fixed because
it is computed from the integrated pre-closure graph rather than supplied by an
independent primary evidence source.

Performance work was included for external targets. During calibration, named
dynamic pairs are retrieved directly from the persistent SQLite pair cache. The
optimizer therefore does not scan the complete incremental cache for every
objective evaluation. The normal full graph is still assembled once after the
fit using the fitted settings.

Calibrated runs write both submitted and effective configurations, a JSON
calibration summary, fitted parameter tables, target probabilities before and
after fitting, optimizer traces, and endpoint-resolution details. The GUI shows
a concise before/after positive-control summary and links every audit artifact.
