# Temporal validation of ranked signaling paths

## Purpose and position in the framework

This optional analysis compares the order of nodes in a proposed signaling path
with a 1, 2, 5, and 15 minute dDAVP phosphoproteomic time course. It is a
post-path **validation/annotation layer**. It is not a node-selection stream, an
edge Bayes factor, or a replacement for the Bayesian path score.

The primary path table remains ordered by the product of edge probabilities.
Temporal validation appends coverage and order statistics and gives sufficiently
measured paths a separate `temporal_evidence_rank`. It never changes node
posteriors, edge posteriors, graph directionality, or the primary `rank` column.

The implementation was adapted from the files supplied in `files.zip` on 14
August 2026. The contributed example TSV was generated from an older path set
and is not a canonical result. The integration recomputes temporal evidence for
the paths generated by each current GUI run.

## Input

The GUI uses:

`data/phospho_data_original.xlsx`

The embedded workbook documentation describes dDAVP-treated and vehicle-treated
rat renal inner medullary collecting duct phosphoproteomics. The four raw sheets
are `1 min`, `2 min`, `5 min`, and `15 min`. Each contains three biological
replicates. For timepoint index `k` and replicate `r`, the integration uses the
positive reporter-intensity pair:

- `C{k}_Replicate{r}_1` for vehicle/control; and
- `V{k}_Replicate{r}_1` for dDAVP/treated.

The response is `log2(V/C)`. A replicate is missing when either intensity is
nonpositive or nonnumeric; missing values are not converted to zero. Sheets are
joined by `(Protein UniProt ID, Position in Protein (A))`. Rows with no usable
gene symbol or protein identifier are excluded and reported only through the
resulting trajectory counts.

## Replicate-aware method

### 1. Per-site, per-timepoint response

For each observed phosphosite/timepoint, the method calculates the mean and
sample variance of replicate `log2(V/C)` values. Absolute response magnitude is
used for timing, so either increased or decreased phosphorylation can indicate
that a node responded. Biochemical sign is not inferred from this score.

### 2. Intensity-dependent variance prior

With three replicates, each raw variance has only two residual degrees of
freedom. To stabilize it, the method bins all usable site/timepoint records by
`log10` median reporter intensity and calculates the median replicate variance
in each bin. Linear interpolation over the bin medians defines the empirical
prior variance `s0²(I)`.

For a site/timepoint with raw variance `s²`, `n` observed replicates,
`d = n - 1`, and configured prior degrees of freedom `d0`, the moderated
variance is:

```text
s_moderated² = (d0 × s0²(I) + d × s²) / (d0 + d)
```

The standard error is `sqrt(s_moderated² / n)`. A two-sided Student-t p-value
is calculated from `|mean| / SE` with `d0 + d` degrees of freedom. This is a
transparent limma/voom-inspired approximation, not an invocation of limma,
voom, or MSstatsTMT.

### 3. Representative phosphosite

Each gene is represented by the phosphosite with the largest peak moderated
absolute t statistic across its observed timepoints. This favors signal-to-noise
over raw fold-change magnitude and keeps one physical site trajectory per gene.

### 4. Peak-p multiplicity correction and gate

Searching across several sites and timepoints can make an unadjusted minimum p
value anti-conservative. The GUI default therefore applies a within-gene
Bonferroni correction:

```text
p_adjusted = min(1, p_raw × number of tested site-timepoints for that gene)
```

A gene enters temporal path scoring when `p_adjusted < alpha` (default 0.05).
The GUI also exposes `none` solely to reproduce the original contributed
analysis. Unadjusted results should be labeled as such.

This correction controls the within-gene site/timepoint search but does not
provide a study-wide false-discovery-rate guarantee across all genes and all
paths. The temporal analysis remains exploratory.

### 5. Monte-Carlo response time

For the representative site, each timepoint response is sampled as:

```text
x_t ~ Normal(mean_t, SE_t²)
```

For every draw, the response time is the absolute-response center of mass:

```text
tau = sum(t × |x_t|) / sum(|x_t|)
```

The default is 2,000 draws with seed 0. These are parametric Monte-Carlo
uncertainty intervals conditional on the fitted approximation. They are not
described as fully Bayesian credible intervals.

### 6. Per-path temporal scores

Only measured genes passing the adjusted significance gate enter the ordering
score. For every path, the output records scored, absent, and measured-but-not-
significant node counts.

For scored path nodes `i < j`:

- `temporal_soft_precedence` is the mean of `P(tau_i < tau_j)` over all ordered
  node pairs. A value near 0.5 indicates little timing information.
- `temporal_kendall_tau_point` is Kendall tau-a on point center-of-mass times.
- `temporal_kendall_tau_mean`, `low`, and `high` summarize the draw-wise Kendall
  tau-a distribution; `low` and `high` are its 2.5th and 97.5th percentiles.

The statistics are undefined when fewer than two nodes pass the gate. A path
receives a `temporal_evidence_rank` only when it meets the configured minimum
coverage (default three scored nodes). That secondary rank sorts by the lower
Kendall bound, mean Kendall value, soft precedence, and finally Bayesian path
probability. The original row order and `rank` remain unchanged.

## GUI controls

Temporal validation is disabled by default because it is lab- and target-
specific and adds raw-workbook runtime. The fourth GUI stage exposes:

- variance prior degrees of freedom;
- significance alpha;
- number of Monte-Carlo draws;
- random seed;
- within-gene Bonferroni or legacy unadjusted peak p; and
- minimum scored path nodes required for a temporal evidence rank.

Progress and cooperative cancellation are checked after every input sheet and
during site- and gene-level batches.

## Per-run output files

When enabled and at least one Bayesian path is found, the run writes:

- `ranked_paths_temporal.tsv`: the unchanged primary path table plus temporal
  annotations and the separate temporal evidence rank;
- `temporal_gene_responses.tsv.gz`: representative site, raw and adjusted peak
  p, gate status, coverage, and response-time interval for every measured gene;
- `temporal_variance_trend.tsv`: intensity-bin prior variances; and
- `temporal_validation_summary.json`: exact parameters, coverage counts, source
  path, and the explicit statement that primary Bayesian ranks were unchanged.

The same summary is embedded in `analysis_summary.json`. The unmodified
`ranked_paths.tsv` is still written as the canonical Bayesian path output.

## Sensitivity analysis

`code/path_finding/temporal_sensitivity.py` sweeps prior degrees of freedom and
alpha. It reports adjusted peak p values by gene, temporal path cells across the
grid, and genes whose pass/fail gate depends on those choices. The default
`prior_df=50` grid point is an intentional over-shrinkage stress test and should
not be treated as a preferred setting.

## Initial integration validation

The validation run
`results/gui_runs/temporal_integration_validation_20260814_v3/` used the current
default ontology-directed Prkaca-to-Aqp2 workflow, 2,000 draws, `prior_df=4`,
`alpha=0.05`, within-gene Bonferroni correction, and a three-node temporal
coverage gate.

- 6,755 valid phosphosite trajectories were loaded.
- 2,661 genes had a representative measured trajectory.
- 237 genes passed the adjusted gate.
- 25 Bayesian paths were preserved in their original order.
- 7 paths had at least two scored nodes.
- 0 paths had at least three scored nodes, so none received an interpretable
  temporal evidence rank under the default coverage rule.

This is an informative negative result: the current experiment does not measure
enough significant nodes along these directed paths to order them reliably. It
should not be converted into evidence against the existence of the paths.

## Limitations and reporting language

- The source experiment is rat IMCD, whereas graph symbols are mouse-oriented.
  Gene-symbol matching is case-insensitive but does not perform a new orthology
  analysis inside this layer.
- Phosphorylation response time need not equal protein activation time, and a
  protein can signal without a measured phosphosite response.
- Absolute LFC discards activation/inhibition sign.
- The normal approximation treats timepoint errors independently and does not
  fit a full longitudinal or TMT generative model.
- Representative-site selection loses multi-site biology and can be sensitive
  to the variance prior; use the sensitivity script.
- A narrow interval or favorable order is supporting temporal consistency, not
  proof of causal transmission.
- An unrankable path means insufficient temporal coverage, not a negative
  biological result.
